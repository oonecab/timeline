## 统一执行命令

```text
python scripts/acceptance.py
```

该脚本按序执行下列四个命令。所有数据库测试使用临时目录，不写用户默认数据库。

| 命令 | 退出码 | 本次耗时 |
|---|---:|---:|
| `cargo fmt --all -- --check` | 0 | 0.119s |
| `cargo clippy --all-targets --locked -- -D warnings` | 0 | 0.289s |
| `cargo test --all-targets --locked` | 0 | 28.269s |
| `cargo build --release --bins --locked` | 0 | 0.642s |

完整执行输出位于 `target/acceptance/commands.log`，机器可读命令结果位于 `target/acceptance/results.json`。再次运行会更新这两份文件。Release 产物为 `target/release/tl.exe` 和 `target/release/tl-mcp.exe`。
